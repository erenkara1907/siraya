# DeskNimbus

**Every desk and room, booked in a tap.** DeskNimbus runs a coworking space end
to end — live desk and meeting-room availability, self-serve booking, member
plans and automatic Stripe billing, from one calm dashboard.

## Quick start

```bash
npm install
npm run dev          # → http://localhost:3000  (demo mode, no keys needed)
```

## Make it yours

Open this folder in **Claude Code** and say **"set up this project"** (or run
**`/setup`**). It asks for your brand, colors, and your **Stripe** key, then
wires it in. By hand? See [`SETUP.md`](./SETUP.md).

## Pages

`Bookings` (overview & today’s queue) · `Spaces` (interactive availability grid) ·
`Members` (plans & credits) · `Billing` (revenue & invoices) · `Settings`.

Built on the GoatStarter template — Next.js 16 · React 19 · Tailwind v4.
